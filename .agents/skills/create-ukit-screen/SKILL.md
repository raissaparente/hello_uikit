# UIKit Screen Creation

## Purpose

Create a small UIKit screen based on a provided specification.

The specification describes the expected behavior and UI. The student is learning UIKit, so the implementation should be simple, explicit, modular, and easy to understand.

## Rules

- Implement only what is required by the specification.
- Keep the implementation small, modular, explicit, and easy to understand.
- Prefer straightforward UIKit APIs over concise, clever, or advanced implementations.
- Use separate methods or small components when doing so makes the code easier to understand, but do not introduce abstractions without a clear purpose.
- Make the structure of the implementation easy for a beginner to follow.
The student should encounter the UIKit code before receiving an explanation of how it works.
